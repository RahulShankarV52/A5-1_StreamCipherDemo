Implementation of A5/1 (GSM Standard)

Stream Cipher Simulation & Analysis

1. Executive Summary

A5/1 is a stream cipher developed in 1987 to protect voice communication in GSM mobile networks. It uses three Linear Feedback Shift Registers (LFSRs) with irregular clocking to generate a keystream.

Architecture

3 LFSRs (19, 22, 23 bits)

Key Length

64-bit session key (Kc)

Clocking

Majority Vote Rule

Frame Number

22-bit public counter

SYSTEM ARCHITECTURE
1

Register Initialization

The internal state consists of three LFSRs: R1 (19 bits), R2 (22 bits), and R3 (23 bits).

  • The 64-bit key is XORed into the registers bit-by-bit.
  • The 22-bit frame number is then XORed in.
  • This "seeds" the random state of the machine.
2

Majority Vote Clocking

To prevent simple cryptanalysis, the registers do not move at the same time. This is the "Stop/Go" rule.

  • The system checks clock bits: R1[8], R2[10], R3[10].
  • A "Majority Bit" is determined (e.g., if bits are 1, 1, 0 -> Majority is 1).
  • Only registers matching the majority bit are clocked (shifted).
3

Keystream Generation

Once mixed, the system generates the encryption stream (Keystream) one bit at a time.

  • The Most Significant Bit (MSB) of R1, R2, and R3 are extracted.
  • They are XORed together: K = R1_out ⊕ R2_out ⊕ R3_out.
  • This bit K is XORed with the Message to encrypt it.
